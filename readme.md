# SoulSync 💜

AI-powered mental wellness platform for students.

## Live Demo

🌐 https://soulsync-nd5b.vercel.app


## Features

- User Authentication (Signup/Login)
- Mood Tracking
- Mood Analytics
- Mood History
- Personal Journaling
- Modern Glassmorphism UI

## Tech Stack

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
